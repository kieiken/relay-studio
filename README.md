# Relay Studio — 0.2.0 alpha 開発版

共通原稿を一度入力し、選んだ媒体へ「今すぐ投稿」から配信するローカルアプリです。媒体ごとの個別原稿、日本語／繁體中文（台灣）、投稿結果と反響の記録に対応します。既定の投稿先は６媒体すべて選択済みです。

**0.2.0はChrome拡張の実機検証中です。六媒体の自動投稿が実証済みの完成版ではありません。** 0.1.4の実投稿テストと、新しい拡張を通したテストは区別します。

## インストール

macOS、Node.js 22以降、Google Chromeを使用します。実行用ZIPを展開し、そのフォルダをCodexまたはClaude Codeで開いて、次を依頼してください。

> INSTALL_WITH_AI.mdを読み、Relay Studio本体と同梱Chrome拡張をインストールして、投稿しない診断を実施してください。

[日本語・台湾繁体字の手順](INSTALL_WITH_AI.md)。配布ZIPは依存ライブラリ同梱。GitHubのSource codeは開発用で、先に `npm ci --ignore-scripts` が必要です。Node実行環境は同梱していません。

Chrome拡張は `extension` フォルダです。Chromeの拡張管理で「パッケージ化されていない拡張機能を読み込む」から選択します。AIの操作環境が拡張管理画面を許可しない場合は、この操作だけ利用者が行います。Chrome Web Storeへの掲載はまだ行っていません。

## 最初の設定と投稿

1. `start.command` または `npm start` で起動し、Chromeで [初期設定](http://127.0.0.1:8792/#settings) を開きます。
2. Facebookページ・Threads・Instagramには自分のIDと利用可能なトークンを設定します。トークンはmacOSキーチェーンに保存します。Facebookはページ用、InstagramはInstagram Loginのプロアカウント用です。
3. 「拡張機能を接続する」を押します。X・note・RedNoteで自分の公式アカウントにログインし、設定画面へIDを入力して「ログインを照合する」を押します。X／noteは@を除いたユーザー名、RedNoteはプロフィールの数字のIDです。
4. 共通のタイトル・本文を入力します。タイトルはnote／RedNote用で、SNS本文へ自動挿入しません。ブラウザ媒体の画像はJPEG・PNG・WebPのファイルを選択します。Instagramは公開HTTPSのJPEG URLを別途指定します。
5. 必要な媒体だけ「個別に編集」へ切り替えます。共通へ戻しても個別原稿は残ります。投稿先のチェックを選び、「今すぐ投稿」を一度押します。未接続や不備があれば登録前に止まり、選択先を黙って除外しません。
6. 日時指定は「日時を指定」へ切り替えます。本体、端末、ネット接続、ブラウザ媒体ではChromeも起動したままにします。ローカル予約は媒体側の予約完了ではありません。
7. 配信一覧で各媒体の結果を確認します。公開後の反響は48時間後に取得し、「最新の反響を取得」で現在値も要求できます。取得不能項目は空欄で、0と区別します。

媒体別のキューを順次実行するため、秒単位の同時公開は保証しません。登録後の原稿は固定され、下書きの変更だけでは登録済みの内容は変わりません。

## 対応する経路

| 媒体 | 投稿経路 | 素材・反響 |
|---|---|---|
| Facebook | 公式API、ページのみ | テキスト。公式API反響 |
| Threads | 公式API | テキスト。公式API反響 |
| Instagram | 公式API | 公開JPEG URL。公式API反響 |
| X | Chrome拡張、公式画面 | テキスト・画像1枚。画面で照合できた反響 |
| note | Chrome拡張、公式エディタ | タイトル・本文・見出し画像。画面で照合できた反響 |
| RedNote | Chrome拡張、公式クリエイター画面 | タイトル・本文・画像。画面で照合できた反響 |

拡張の操作経路は実装済み、実機での公開から削除までの一貫検証は継続中です。公開URL・全文・本人・実公開日時を照合できない場合は「結果の照合が必要」とし、成功扱いや自動再送をしません。特にRedNoteの審査待ち、相対日時しか表示されない画面では自動確定できません。

Facebook／Threadsは画像付きに未対応です。媒体カードの「この媒体だけ本文を引き継ぎ、画像を外す」で個別に設定できます。動画投稿、素材ホスティング、OAuthの代行は含みません。Xの従量課金API、AI原稿生成APIは呼びません。

## 安全な停止と反響

- 拡張はローカルアプリとX・note・RedNoteの公式ドメインだけにアクセスします。Cookie取得権限、全サイト権限、外部分析への送信はありません。接続用トークンはChromeのセッション領域に保存します。
- 投稿前に本人と入力内容を照合し、サーバーに最終操作を記録してから公開します。処理中の再起動・通信切断・結果不一致は自動再送しません。再送前に公式画面の確認が必要です。
- 拡張未接続のまま予定から15分を超えた投稿は停止します。設定画面から再接続してください。本体再起動後はChromeでアプリ画面を開き直すと接続情報を更新します。
- 設定の一時停止で自動配信・反響取得を止めます。既に開始した外部送信は取り消せません。
- 反響は実公開日時＋48時間を基準に、48〜54時間の実測だけを「48時間観測」とします。それ以前・以後の取得は「現在累計」。送信操作時刻を実公開時刻に代用しません。
- 失敗した反響取得は無条件再試行しません。原因を解消後、「最新の反響を取得」で再要求するか、公式画面の値を出典・取得日時付きで記録できます。
- 数値を取得できない項目を0で埋めず、異なる媒体の数値を合計しません。

## 保存先と利用範囲

原稿・画像・接続先・結果は `~/Library/Application Support/Relay Studio` に保存します。APIキーはアプリ専用macOSキーチェーンに保存し、JSONや配布ZIPへ含めません。既存の別アプリのキーや予定を自動移行しません。

サーバーは127.0.0.1のみで待受し、Host・Origin・Fetch Metadata・リクエストトークンを確認します。この版は信頼できる単一利用者のローカル端末向けです。同一端末で任意のプログラムを実行できる第三者を隔離する認証境界は備えません。共有端末や公開Webサーバー向けではありません。

UIの言語は切り替えても、投稿本文・アカウント名・入力中のキーは翻訳せず、予定日時も変更しません。

## 検証と配布

`npm test` は状態遷移、二重送信防止、接続元制限、画像受け渡し、48時間判定、既存データ保持、インストーラを検証します。公式画面のDOMに依存する拡張は別途実機検証が必要です。

`npm run package` は許可リストのファイルだけをZIPへ入れます。拡張・依存ライブラリ・インストール手順を同梱し、キー・履歴・個人パス・レビュー生ログは除外します。

2026-09-22の0.1.4検証では、Meta3は本体のAPI、X／note／RedNoteは手動で投稿・照合・削除を実施しました。0.2.0の拡張検証をその結果で代用しません。Claude Fableの独立レビューと採否は [DESIGN-REVIEW.md](DESIGN-REVIEW.md) に記録します。

一般向け販売には、媒体提供条件への適合確認、署名済み配布・更新、接続支援、対応範囲の明示も必要です。本リポジトリにはライセンスをまだ指定していません。依存ライブラリのライセンス表記は配布物に保持します。
