# Relay Studio Bridge

対象：Google Chrome Manifest V3。X・note・RedNote用です。既存の個人向け拡張とは別の拡張として導入します。

1. Chromeで `chrome://extensions` を開きます。
2. デベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」で、このREADMEとmanifest.jsonがあるフォルダを選択します。
3. Chromeで `http://127.0.0.1:8792/#settings` を開き、「拡張機能を接続する」を押します。
4. 対象SNSにログインし、本体の設定へ本人IDを入力して「ログインを照合する」を押します。別のChromeプロファイルのログインは使いません。

権限：storage（接続セッション・中断記録）、alarms（起動中の定期確認）、scripting（公式画面の入力・照合）。対象ホスト：localhost、127.0.0.1、x.com、note.com、editor.note.com、creator.rednote.com、www.rednote.com。ローカル画面からの指示は8792番だけ受け付けます。全サイト・Cookie・閲覧履歴を取得する権限はありません。

投稿時に専用タブを開きます。本人IDを照合し、内容を入力後、本体に最終操作を記録してから公開します。処理中は専用タブの内容を変更しないでください。公式画面の構成変更、ログアウト、画像失敗、審査待ちでは停止します。公開済みか不明な処理は自動再送しません。

拡張更新時は同じフォルダを保ち、Chromeの拡張カードの更新ボタンを押してから、本体画面を更新します。本体再起動後も本体画面を開いて接続セッションを更新してください。データを移動して拡張IDが変わる場合は接続と本人照合をやり直します。

實際操作：在 Chrome 擴充功能管理頁面啟用開發人員模式，載入此資料夾。在 Relay Studio 設定畫面連接擴充功能，再核對各平台登入帳號。更新後請重新載入擴充功能與本體畫面。擴充功能不收集密碼或 Cookie；結果不明時不會自動重送。
